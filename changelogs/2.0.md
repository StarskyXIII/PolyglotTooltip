# What's new in PolyglotTooltip 2.0

## New since 1.6.0

- New **Forge** builds for Minecraft 1.16.5, 1.18.2, and 1.19.2.
- New **Fabric** builds for Minecraft 1.20.1, 1.21.1, and 26.1.2. Install Fabric API alongside them.

## In-game improvements

- Search by translated names in Pretty Pipes terminals. Changing your extra languages also updates search results in more screens, including Refined Storage and AE2 pattern terminals.
- Fixed JEI startup crashes and missing translated fluid names on affected versions.
- Fixed a startup crash on Fabric 1.20.1 with EMI, Just Enough Characters, and LDLib installed together. Restored translated item search in GregTech Odyssey's AE2 terminals.
- Fixed saving or removing extra languages in Carbon Config, so your language list keeps its intended order.
